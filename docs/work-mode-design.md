# CharaDock Work設計

## 目的

デスクトップコンパニオンとの会話の軽さを保ったまま、Codex app-server に通常のアプリ開発・文書作業を依頼できるようにする。Workは Codex app-server 接続時だけ利用可能とし、OpenAI API 接続時はChatに固定する。

## UI方針

- 会話画面のヘッダーに小さな `会話 / 作業` の2択だけを置く。新しいサイドバー項目は増やさない。
- Workへ初めて切り替えた時だけフォルダー選択を開く。以後は入力欄の上に `作業先: avatar_codex` のチップを1個表示する。
- 入力欄、音声入力、チャット履歴はChatと共用する。
- コマンド、ファイル変更、テスト結果は逐次並べず、ターンごとに1枚の「作業ログ」へ折りたたむ。
- 完了時は `変更したファイル数 / テスト結果 / 差分を見る` だけの小さな結果カードを表示する。
- 承認が必要な操作だけ会話中に確認カードを出す。常設のターミナル、ファイルツリー、差分ペインは設けない。

## 安全な初期値

- 作業先は利用者が選んだ1フォルダーに限定する。
- 初期権限は workspace-write、追加権限は必要時に確認する。
- Chatでは現在どおり読み取り専用のコンパニオン応答にし、ファイルを変更しない。
- モード、作業先、実行中かどうかを入力欄付近に常に短く表示し、意図しない作業を防ぐ。

## 実装段階

1. モード切替、フォルダー選択、app-server の作業ターン。（実装済み）
2. 折りたたみログ、完了カード。
3. 差分ドロワー、承認カード、作業の中断と再開。
4. よく使う作業先と定型タスク。常設ボタンは増やさず、作業先チップのメニューへ収める。

この構成なら普段は現在の会話画面とほぼ同じで、作業時にだけ必要な情報が現れる。
