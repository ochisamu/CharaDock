# StackChan接続プレビュー

対象は公式M5Stack StackChan K151/CoreS3。実機未接続の段階で実装・ビルド検証したものです。
今回は書き込み・実機操作・公開・開発アプリの再起動は行っていません。

## 操作

設定 → ESP32デバイスで表示デバイスをOFFにし、機種をStackChanへ変更します。
有効化後、初回はUSBポートを選択してWi-Fiを設定します。
RLCDとStackChanのポート・ペアリングは別プロフィールに保存します。
同時に使える表示デバイスは一台で、ATOMの設定は独立しています。

頭に約0.5秒触れてから話し、離すとPCの認識・会話・TTSへ送ります。
再生中／回答待ちに触れると割り込み、触れ続けると次の入力を開始します。
PC生成PCMのストリーミングなので、ESP32にsanoTTSは入りません。
Chat/Work/PTT Live、既存音声処理、Liveの5分アイドル終了設定を共有します。

カラー画像は通常のキャラレイヤーから合成し、RGB565で原子的に転送します。
一瞬キャラ画像を見せた後は、口パク・瞬き・小さな視線移動のあるネイティブ顔を表示。
状態LEDと日本語字幕を併用します。アップロード画像自体の口パクは未対応です。
サーボは起動時OFF。安全を確認して設定画面の首振りONを押した接続中だけ動きます。
首振り設定は永続化しません。切断・通信経路の交代では再びOFFになります。

## 検証

```sh
node --test desktop/tests/stackchan-*.test.cjs
node --test desktop/tests/*.test.cjs
```

ローカルTCP/UDPの模擬デバイスで探索・相互認証・PTT順序を検証します。
音声の11byte開始設定、リング満杯時の再試行、キャンセル、カラー転送CRCも検査。
ファーム側はCharaDock-ESP32の`firmware/stackchan`をビルドします。

実機接続後にUSB/Wi-Fi双方の短文・長文再生、認識、割り込み、再接続、音量、
マイク感度、サーボ可動域を確認する必要があります。
ハンズフリー、AEC/full-duplex、RLCD時計・温湿度画面はこのプレビューでは未対応。
180文字まで送信する字幕は画面下部でクリップされ、自動ページ送りはありません。
