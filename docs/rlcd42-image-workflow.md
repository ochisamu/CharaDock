# RLCD 4.2 キャラクター画像変換

RLCD 4.2設計でPC側の役割とした画像処理を、再現可能な手順として定める。ファームウェアは変換済みの400×300・1bit Portraitを保存・描画するだけとする。

製品同梱キャラクターは、画像生成で作った次の4枚の専用モノクロ漫画絵を持つ。通常・瞬き・口半開き・口開きは同一キャンバス、同一構図で、表情部だけを変える。

- `rlcd42-portrait.png`
- `rlcd42-portrait-blink.png`
- `rlcd42-portrait-mouth-half.png`
- `rlcd42-portrait-mouth-open.png`

カラー原画から作る場合は、同じキャラクターを白地、強い黒輪郭、選択的な黒ベタと粗い斜線ハッチを持つ4:3の漫画絵へ画像生成する。顔・首・肌は白を保ち、黒ベタは後ろ髪の奥、衣装の影側、小物のアクセントへ分離して置く。微細な網点、点描、連続グレー、勾配、顔面の黒塗りは使わない。通常絵から目または口だけを編集して残り3枚を作り、専用絵は輪郭を再抽出せず直接1bit化する。4枚の一部だけを使うことは禁止し、不足・重複・寸法差・構図の大きな移動は追加時の検証で拒否する。

専用4枚がない既存`.purupuru`は互換性のため下記の共通変換へフォールバックする。キャラクターID、髪色、肌色に依存する専用しきい値は設けない。

## 完全新規キャラクター

アプリの「一枚絵からキャラクターを追加」は、デスクトップ用6表情と前髪レイヤーに加え、同じ入力画像からRLCD用4表情も生成する。生成ワーカーは`.agents/skills/build-purupuru-avatar/SKILL.md`の共通契約に従い、次を満たさない素材をインストールしない。

1. 400×300以上、4:3、4枚同寸法。
2. 平坦な不透明白背景、強い黒輪郭、選択的な黒ベタ、8px以上のまとまりを持つ粗い斜線ハッチ。色、グレー陰影、細かな網点、点描、ディザ、テクスチャ、顔や肌の黒ベタを使わない。
3. 通常絵を基準に、瞬きは両目だけ、口差分は口だけを変更する。
4. 顔、髪、衣装、アクセサリ、クロップ、線幅を固定する。
5. 4枚を個別に目視し、400×300へ変換した全フレーム比較表も確認する。

外部`.purupuru`にも専用4枚を含められる。manifestに次を追加するか、同名ファイルを`rlcd42/`へ置く。4枚は任意だが、含める場合は必ず一式にする。

```json
{
  "rlcd42": {
    "neutral": "rlcd42/rlcd42-portrait.png",
    "blink": "rlcd42/rlcd42-portrait-blink.png",
    "mouthHalf": "rlcd42/rlcd42-portrait-mouth-half.png",
    "mouthOpen": "rlcd42/rlcd42-portrait-mouth-open.png"
  }
}
```

## 変換の共通仕様

内蔵キャラクターと追加した`.purupuru`キャラクターへ、同じ決定的な変換を適用する。

1. 通常時の後ろ髪、顔・体、前髪PNGを白地へアルファ合成する。
2. `faceCenterSetup.center`があればクロップの弱いヒントに使い、なければ中央寄せへフォールバックする。
3. 400×300へ縮小し、実際に使われている輝度範囲を正規化する。専用漫画絵は薄いアンチエイリアス縁も少し拾う共通しきい値で、実機上の線の細りを補う。
4. 事前平滑化をせず、縮小で弱くなった局所ディテールを軽く戻す。
5. 高コントラスト境界の暗い側だけを輪郭にし、周囲より暗い1px線を保持する。
6. 専用`manga`素材では生成時に置いた黒ベタと粗いハッチを保持する。専用素材がないカラー画像のフォールバック変換では、色面と緩やかな陰影を白へ整理し、反射液晶上で粒に見える網点を作らない。
7. 顔中心はクロップだけの弱いヒントとし、肌色、髪色、キャラクターID、キャラ専用しきい値は使わない。
8. `raw1-msb`へ格納し、内容revision、画面全体と顔周辺の黒画素率を記録する。

連続階調の雰囲気を優先したい素材には、固定Bayerディザの`illustration`も残す。

## プレビューと回帰確認

変換パラメータを変える前後で、全素材の比較表を生成する。

```bash
npm run rlcd42:previews
```

生成物はGit管理外の`work/rlcd42-previews/`へ置く。各キャラクター4表情の400×300 PNG、4列の一覧画像、各フレームのrevisionと黒画素率を含むJSON manifestが出力される。

追加キャラクターの展開先フォルダも、同じ変換器へ直接渡せる。

```bash
node scripts/build_rlcd42_portrait_previews.cjs \
  --output work/rlcd42-custom-preview \
  /path/to/imported-character
```

変換処理を変更したら自動テストも実行する。

```bash
node --test desktop/tests/rlcd42-monochrome.test.cjs
```

テスト対象は、決定的な1bit格納、平坦な色面に網点を作らないこと、1px線の保持、クロップ範囲、4表情の差、レイヤー不一致拒否、製品同梱5キャラの黒密度である。専用素材の400×300出力は画面全体の黒画素率を概ね10〜18%、顔周辺を36%未満に保つ。これはキャラ別の固定値ではなく、薄すぎ・黒潰れを検出する共通受け入れ帯である。反射、視野角、カメラのモアレはPCプレビューだけでは判断できないため、最後は必ず実機写真で受け入れ確認する。

## 反射液晶上のアニメーション

ST7305上で全身Portraitを連続移動させると、同じ輪郭が隣接画素へ重なって残像・にじみに見えやすい。そこで常時更新はせず、待機中だけ7～14秒おきに1～2pxの横または斜め移動を一度行い、0.65～1.2秒静止して原点へ戻す。瞬きと口パクを優先し、録音・再生・会話・環境ダッシュボード中は全体を固定する。

これはコハク専用の補正ではない。内蔵キャラクターと任意追加キャラクターのどちらにも同じ規則を適用し、髪色・肌色・キャラクターIDを条件にした処理は追加しない。
