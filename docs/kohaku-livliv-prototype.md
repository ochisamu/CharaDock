# LivLivモデルとコハクの表示

キャラクター設定 → 見た目で標準、LivLiv、Mesh Avatarを選ぶ。名前・性格・声・会話は同じキャラクターに残る。Linkでも見た目とLivLivの調整を共有する。

## 原画の顔を維持する

リビジョン3で、生成した目・口・顔・髪の分離を取りやめ、元の1254px原画と登録済みの表情パッチへ戻した。目や口は拡大・再生成せず、同じ座標へ配置する。目消しは表情パッチの下だけに限定。通常時の不透明な顔領域は原画とピクセル一致する。生成素材とプロンプトはv2フォルダーに保存してあるが、現在の表示には使わない。

透明な余白のない切り出しをLivLivへ渡すと、格子の端で肌色が伸び、顔の輪郭に段差が出る。全ての表情パッチに8pxの透明な余白を付け、原画の描画部分を変えずに防ぐ。

コハクの通常表示は8レイヤーに登録し、表情用レイヤーを追加する。首振り、表情、まばたき、5口形を使う。原画の見た目を優先し、瞳の独立移動と分離した髪の物理は無効にした。眉は表情差分で切り替える。独立した瞳や髪を持つ読み込みモデルでは、そのモデルのリグで動く。

品質上の不変条件: 動かせる部分を増やすために既存キャラクターの目の形・大きさ・位置・顔の輪郭を再生成で変えない。元絵と同じ寸法・座標の比較に加えて、実WebGLで通常顔と表情の境界を目視確認する。素材の検証成功だけで表示品質の成功とはしない。

## モデルの読込と操作

- PCの「LivLivを読み込む」から.livliv / .zip、またはモデルフォルダーのmodel.jsonを選ぶ。Linkは.livliv / .zipをアップロードできる。
- モデル独自の表情と強さ、うなずく・首振り・首かしげ・弾む・照れる・まばたき、居眠りを操作する。
- 視線、顔/全体の画角、位置、拡大率、全15パラメーター、自然な動き、停止・再開、リセットを使える。
- PNG保存はモデルの透かしを含む。PCは保存先を選び、Linkは端末へダウンロードする。
- 調整はプロフィールのlivliv-controls.jsonへキャラ・モデルごとに保存する。外見切替後の古い操作、期限切れ・重複したしぐさは描画しない。しぐさは再接続時に再生しない。
- TTS/Liveの既存の音量通知で口を動かす。発話中は音声の口パクを優先する。追加のマイク・音声再生キューは作らない。

v3/v4のモデルを上流のreadModelで検証し、ZIPは上流の制限付きリーダーで展開する。80MB圧縮/256MB展開、2048エントリー、画像8192px/64M画素、JSONと頂点数の制限を適用する。参照する画像・keyformsだけをプロフィールへコピーし、モデルの外のパスを拒否する。作者・ライセンス・透かしは維持する。配信は選択中のモデルだけ、Linkはペアリング済み端末だけに限定する。

カメラ追跡、VRM、PNGTuberは今回追加しない。

## リビジョン5: 表情の描き分け

既存の笑顔・まばたき・5口形を維持し、考える・困る・怒る・驚くの4種類を追加した。内蔵image_genで元絵を参照した4枚の編集マスターを作成し、眉と口だけを原画座標で局所合成する。元の瞳・まつ毛・輪郭・髪・衣装は変更しない。髪マスクと目の保護多角形で、眉の差分が前髪や元の目を上書きしないようにする。肌の境界は限定した色差補正とフェザーでなじませる。

assets/kohaku-livliv-sources/expressions-v5/generation.jsonに正確なプロンプトと画像SHA-256、scripts/kohaku-expression-patches.cjsに登録領域と合成処理を保存する。通常の再ビルド・再生は画像生成サービスを呼ばない。

新しい4種類はモデル独自の表情としてPC・Linkの選択欄へ出す。判断アシストの感情も同じ表情へ割り当てる。悲しい→困る、呆れ→考えるは絵を共用し、目の開き・姿勢は感情に合わせる。他の読込モデルはそのモデルに存在する表情IDを優先し、無い表情は中立へ戻す。手動選択は一時的な自動感情より優先する。

眉・口の表情レイヤーには、眉だけのtalkテクスチャも持たせる。発話中は生成した静止口を描かず、既存の音声連動口パクを使う。表情レイヤーに瞳を含めないため、まばたきも継続できる。表情の強さ0は元の顔へ戻り、終了・切替・再接続で一時表情を持ち越さない。

表情改修の最終確認: JavaScript 1,222件・Python 58件が成功。PC実IPCとペアリング済みLinkの感情イベントで4種類の追加表情を選択でき、手動表情の同期、口パク・まばたき併用を確認。通常プロフィールの実speech.cpp再生中も困り顔と口パクを同時に確認し、音量通知233回・最大開口1.0を記録した。証跡はwork/evidence/kohaku-livliv-expressions。
