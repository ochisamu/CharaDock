# VRMの見た目を読み込む

設定 → キャラクター → 「VRM・LivLivを読み込む」で `.vrm` を選択します。キャラクターごとの「見た目」から、標準・Mesh Avatar Studio・LivLiv・読み込んだVRMを切り替えられます。声、性格、会話履歴は同じキャラクターのものを引き継ぎます。

初期表示はバストアップです。「表情・しぐさ・表示調整」の「カメラと構図」で、焦点距離（35mm判換算、35–250mm）、拡大率、上下左右の位置、顔中心表示を調整できます。150mmのプリセットを選ぶと、バストアップの大きさをおおむね保ったまま遠近感が弱まります。焦点距離はモデルごとに保存されます。動きの大きさ、視線、表情、うなずきなども調整できます。「会話に合わせる」では既存の会話・判断アシストの表情指示を使い、表情を選ぶと手動指定を保持します。PNG保存にも対応します。

音声再生中の口パクには、従来と同じTTS / Liveの音量と口開閉の信号を使います。新たな音声再生やマイク取得は行いません。VRMの母音・まばたき・表情モーフを動かすため、モデルに該当する形状が必要です。音素を認識する方式ではありません。分離された眉・目・口の表情を持つモデルでは口パクと表情を両立し、口を固定する一体型の表情しかないモデルでは発話中にその表情を弱めます。

CharaDock Linkも同じプロフィールの見た目・設定を使います。ペアリング後に表示・表情の変更・VRM読込ができます。設定変更だけではモデルを再ダウンロードしません。PCとLinkは各端末でローカル描画します。

VRM 0.x / 1.0とWebGL2に対応します。1ファイル128MB以下、内蔵PNG/JPEG/WebPテクスチャ、最大8192px・合計128Mピクセル、最大4M頂点です。外部参照、Draco / Meshopt / KTX2圧縮には対応しないため、画像を内蔵し圧縮なしで書き出してください。

モデルは元のバイト列と作者・利用条件を保持してプロフィール内に保存します。設定画面に作者とライセンスを表示します。ユーザーのモデルはアプリ配布物やGitには含めません。

検証: `node --test desktop/tests/vrm-avatar.test.cjs`。Windows Electronで `scripts/verify-vrm-renderer.cjs SOURCE VRM OUTPUT` は実WebGLと実モーフ、`scripts/verify-vrm-avatar.cjs SOURCE VRM FRESH_OUTPUT` は実際の読込IPC・切替・PNG保存・ペアリング済みLink・アップロードを検証します。後者は独立したテストプロフィールを作成します。
