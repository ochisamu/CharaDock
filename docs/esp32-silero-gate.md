# ESP32通常会話のSileroゲート

ATOM Echo / RLCD 4.2 のUSB・Wi-Fi共通入口で使用する。
端末のRMS判定は送信開始の候補にすぎず、PCのSileroが声を確認するまで
通常音声認識、会話送信、再生停止、回答字幕の消去を行わない。

- モデルは既存のSHA-256検証付きSilero。PCマイクとは別の検出器をデバイスごとに作る。
- 感度は `normal`（閾値0.5、最小発話0.16秒）。入力は16kHz mono PCM16。
  強めの `low` では呼びかけを落とすという実機報告を受けて調整。
  拒否ログは入力時間・RMSのみを残し、録音や文字列は保存しない。
- 最大約0.5秒の先行バッファを保持して、声の判定に使った語頭もASRへ渡す。
- 声のない候補は会話へ送らず、エラー表示なしで待機へ戻す。
- 通常TTSのデバイス再生中と終了後800msはハンズフリー候補を全体ごと破棄。
  残響を次のユーザー発話として確定しない。声による再生中の割り込みはできない。
- `push-to-talk`モードでは再生抑止を適用せず、Sileroの声確認のみ行う。
  現行プロトコルではハンズフリーモード内の強制ボタン録音を区別できないため、
  その場合はハンズフリーの抑止条件が適用される。
- Liveは既存経路を維持する。モデル準備失敗時にゲートを無効化して通すことはしない。
- モード切替、割り込み、切断時は候補と検出器を破棄する。

テレビ音声や他人の声を本人の声と区別する機能ではなく、全ての物音を必ず拒否する保証もない。
短い相づち・小声の取りこぼしは実機で調整する必要がある。

検証:

```
node --test desktop/tests/device-speech-gate.test.cjs
node scripts/verify-device-silero.cjs PATH_TO_INSTALLED_SILERO_DIRECTORY
```

後者はnative依存を入れたOSのNodeで実行する。既存モデルと同梱音声のみ使用し、
マイクの録音、認識APIへの送信、スピーカー再生は行わない。
