# Jev呼びかけ判定（通常TTS）

設定のJevを有効化してAPIキーを保存し、「ハンズフリーの呼びかけ判定」を標準または厳しめにします。初期値はOFFです。ON時にキー未設定・通信失敗なら会話へ送信しません。

PCでは音声設定の開始方法をハンズフリーにして、デスクトップのキャラ横マイクで待受を開始／停止します。認識後の自動送信もONにしてください。アプリ起動だけでマイクを開始する変更ではありません。

ATOM Echo／RLCDではデバイス設定のhands-free時に適用します。push-to-talk設定の手動入力は対象外です。入力モードは録音開始時に固定します。Liveは対象外です。

音声検出→文字起こし→Jev判定→既存の自動送信の順です。VADの発話・無音検出は変更しません。Jevへの1回の問い合わせで「意味のある会話か」「宛先は誰か」を別々に判定します。標準・厳しめとも、咳払い等に由来し得る単独の「フッ」「アッ」や、会話として不明瞭な断片は除外します。文字数による一律除外はせず、「はい」など意味のある短い返答は残します。

意味のある発話について、標準は明確に他人宛て・独り言のものを除外し、宛先が曖昧な文も送信します。厳しめは確実な呼びかけ・直前の回答への返事・単独の挨拶を通します。「こんにちは」は名前なしで会話開始できますが、「田中さん、こんにちは」や引用は挨拶として許可しません。通信失敗・不正応答はどちらも保留します。PCには判定中・除外・失敗を表示します。

Jevは文字起こし結果のみを見るため、実際の音が咳かどうかは分かりません。咳が完全な文章に誤認識された場合や、テレビの挨拶などは除外できないことがあります。

Jevには認識文と、最大30秒前（厳しめ15秒）の直近回答の冒頭600文字を送ります。判定ログには本文・キーを出しません。除外した文は表情判定や音楽操作にも渡しません。

これは話者認証ではありません。会議・テレビ・独り言を確実に識別できる保証はなく、会議中は明示的にミュートしてください。認識中のデバイス表示は既存挙動を維持します。
