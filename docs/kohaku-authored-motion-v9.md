# コハク作画アニメーション v9

現状を `0ec71fb` で保存した後、ユーザー提供の4 ZIPから統合。
以前のコハク・表現拡張を置き換える。ニケ・任意キャラ・RLCD用素材は不変更。
設定フラグは従来の `jevKohakuPerformanceEnabled` を維持し、ON/OFFも引き継ぐ。

## 操作

標準コハクを選択し、設定のJev連携・表情選択と
「コハク・作画アニメーション（v9）」をONにする。従来どおり既定OFF。
Jevは既存の会話分類で状態を選択するだけで、フレームごとの呼び出しはない。

| 会話入力 | 新素材 |
| --- | --- |
| thinking、ponder、explain、recoil | 首かしげ |
| listening、soft、reassure | 傾聴 |
| happy、celebrate、nod | うれしい同意 |
| exasperated | 疑いの横目 |
| 会話・音声入力がない待機時 | 低頻度のあくび |

動画を貼り付ける方式ではない。PNGの顔体・髪をCanvas/WebGLで合成し、
既存の音声レベル→口3段階、瞬きコントローラへ接続する。
首かしげ中も口・目の局所パッチだけを更新し、通常姿勢への即時復帰はしない。
新しい表情4種は、添付の顔領域マスクで登録済みセルを顔体の下地へ合成する。
髪の根元・飾りは固定し、毛先に小さな独立バネ変位を加える。

## 動きと切り替えの改善

- 呼吸・左右上下の待機揺れ・小さな首の動き・胸の呼吸・発話時の反応を追加。
  既存の待機揺れON/OFF、呼吸・傾き・声の動きの強度設定を引き継ぐ。
- 首のバネは表情を割り込ませても現在の位置と速度を維持する。
  新しい表情は首が通常位置へ戻り切るまで待たず、顔の内側で開始する。
- 48コマと両端の高解像度画像を同じ連続列で補間。丸めによるコマ飛びと
  終端の別画像への即時切り替えをなくした。
- 表情同士の切り替えは表示中のセルから次の開始セルへ直接移行し、
  「旧表情→一瞬通常顔→新表情」の迂回をしない。会話中はピーク表情を保持する。
- 目・口・眉の局所形状を、表示中と次の原画の両側で位置合わせしてから混ぜる。
  首かしげ中の探索領域も顔に追従。口は暗い輪郭だけでなく内側の色も検出する。
- 顔マスクを内側へ縮め、元の頭・顎の輪郭は保持する。目・口の変化にも
  中間値を設け、発話開始・終了や瞬きで急に別の顔を貼り付けない。
- 毛先は首の速度に遅れて追従する。OSの動きを減らす設定では体と髪の揺れを停止。

髪の「ふわっと感」調整では、中間の長さと毛先を別のバネに分離し、深さに応じた
しなりを追加した。毛先は少し柔らかい減衰で頭の動きを追いかけ、弱い戻りを伴う。
横方向だけでなく上下方向も遅れて動く。波の位相は左右で少しずらすが、フレームごとの
ランダムなノイズは加えない。顔・髪の根元・飾りはこの独立変位では動かさない。
既定の毛先サンプル（1254px原画の380,950、10秒間）では左右約−10.4〜+11.5px、
上下約−2.4〜+2.5px。表示時はキャラの縮小率に応じて小さくなる。
「髪の揺れ」「髪のバネ」を既存設定から接続し、揺れ0・凍結・動きを減らす設定では停止。
待機揺れOFFでは待機時の波を止め、会話による頭の動きへの追従だけを残す。
原画上の独立変位は滑らかな制限で横22px・縦9px以内に収める。
ふわっと感調整後はアプリ1056件・静的58件、420フレームの切り替え回帰検査、
実ElectronのWebGL/Canvas2D描画検査が通過。30/60/144fpsの安定性、長時間の停止復帰、
首の反転時の連続性、最大強度でもメッシュが裏返らないことも検査する。

提供された3セルを補間する範囲なので、全表情を連続作画した動画やLive2Dモデルと
同等の再現ではない。中間フレームの淡い混合は残り得る。数値検査だけで
自然さを保証せず、比較動画・中間フレームの目視確認も行う。

## 実装範囲と制限

- 元パッチは古いHEADへのプレビュー専用。無条件適用・付属スクリプト実行はせず、
  現行のキャラ選択・Jev・配布・静的サーバーに手動で接続した。
- 48コマの首かしげは添付の透明レイヤー補間を利用。
- 新4種は原画3セルを短くブレンドする。プレビュー動画のRIFE補間品質を
  そのまま再現する実装ではない。全v8作画キーは今回の添付に含まれない。
- 首かしげ中の目・口は3点位置合わせの局所パッチ。全顔へのyaw/スキューは掛けない。
  独立作画された全ポーズ×6差分と同等の品質保証ではなく、視覚調整の余地がある。
- 残っている旧手ポーズ素材は後方互換・再制作テスト用。PCのコハク拡張では送らず、
  起動時もデコードしない。OFF時は従来の標準コハクへ戻る。
- 読み込み失敗・描画異常時は通常描画へフォールバック。
  キャラ変更・OFF時はAbortControllerとdisposeでロード・画像・GPUを解放する。
- decoded画像は最大640px、計約130.4 MiB。GPU髪テクスチャは最大8枚。
  ブラウザ・旧基本素材・一時Canvas等のメモリは別。OSの動きを減らす設定では
  体・髪の揺れと局所変形を停止し、口・目は維持する。
- RLCDの1bit線画、マイク、Wi-Fi、音声再生の処理は変更しない。ファーム書換え不要。

## 検証手順

```bash
node --test desktop/tests/drawn-pose-runtime.test.cjs
npm run test:desktop
uv run python -m unittest tests.test_project_static
```

Windows Electronで、別プロファイルとローカル静的サーバーのみを使ったテスト:

```text
electron scripts/kohaku-motion-ui-smoke.cjs SOURCE FRESH_OUTPUT
```

6状態のPNG、首かしげ＋口・閉眼、WebGLとCanvas2D fallback、キャラ変更・OFFを確認。
統合時はアプリ1044件・静的58件が通過。Windows Electronで100回のRAF中51回の
描画更新を確認した（1.66秒、約31描画/秒）。これは検証環境での観測値で、性能保証ではない。
音声は合成入力値を用いた描画検証で、実マイク・実TTS・実Jevの会話テストではない。
`?kohakuMotion=1` は検証用の状態確認APIを出す。OBSではこのクエリだけでは有効化せず、
標準コハクかつスナップショットの明示フラグを必須とする。

切り替えの回帰検査（420フレーム、30fps、合成入力。個人プロファイルやAPIへ接続しない）:

```text
electron scripts/kohaku-motion-transition-qa.cjs SOURCE FRESH_OUTPUT
```

待機→首かしげ→喜び→疑い→傾聴→通常→あくびと、発話・瞬きの割り込みを検査する。
各フレームのPNGと `metrics.json` を出力し、全体・顔の差分上限、瞬きの中間値、
待機中の動き、首の即時リセット防止をassertする。差分上限はこの検証シーケンス用で、
美しさや別GPUでの完全一致を保証するものではない。

今回の調整では複数案を描画して見直し、同じシーケンスの最大フレーム差分は
全体9.45→6.96、顔14.55→8.49（RGBAからの差分指標）となった。
切り替え改善時のアプリ1052件・静的58件の検査が通過。実UIの描画・フォールバック・
キャラ切り替え検査も行う。素材の再生成、追加のJev呼び出し、音声処理の変更はない。
