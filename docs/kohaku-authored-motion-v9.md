# コハク作画アニメーション v9

現状を `0ec71fb` で保存した後、ユーザー提供の4 ZIPから統合。
以前のコハク・表現拡張を置き換える。ニケ・任意キャラ・RLCD用素材は不変更。
設定フラグは従来の `jevKohakuPerformanceEnabled` を維持し、ON/OFFも引き継ぐ。

## 現行方式：首かしげの破綻・残像への再対応

実ユーザーの確認で、以前の「修正済み」判断は不十分だった。48コマの試作素材の顔に、
正面の表情・瞬き・口を3点アフィン登録と局所変形で載せる組み合わせが破綻していた。
口の抽出成功やフレーム差分の小ささだけでは、二重顔や自然さを保証できない。
**以下の旧方式の説明は経緯として残すが、現行描画では使わない。**

- 光学フローの48コマと別作画の傾き端点は保管のみ。ランタイムではデコード・描画しない。
- 正面の一つの頭を最大約10度回転。目・鼻・口・頬・髪の根元には同一の回転を適用し、
  輪郭や顔パーツを引き伸ばさない。変形するのは首から肩の広い帯のみ。
- 表情は同じ座標系の原画を使い、二つの顔を透明に混ぜない。
  短い瞬きの閉眼中に表情の原画を交換する。限られた3セルを連続作画に見せる保証はしない。
- 目・口は下地から分離して、左右一つずつの目・一つの口だけを描く。
  開閉中も二つの唇をクロスフェードしない。目の除去領域には白目・琥珀色の虹彩も含める。
  目の下地は閉眼原画から薄いまつげだけを除去し、頬の作画・色を保持する。
  表情原画ですでに目を閉じている場合は、さらに押しつぶす瞬き処理を重ねない。
- 首のバネによる割り込み時の位置・速度継承、口パク、瞬き、体と髪の独立した浮遊感は維持。
  動きを減らす設定では首の回転と自動の切り替え瞬きを停止する。
- 実デコードは20枚（約31.25 MiBのRGBA）へ減少。保存されている全素材の検証予算は別。
  他キャラ・RLCD・音声・Jev分類・個人設定は変更しない。
  GPUコンテキスト喪失時もCanvas2Dへ移り、顔だけ正面・髪だけ傾きという不一致を避ける。

回帰検査は、顔の距離・面積が回転しても保存されること、首から肩を含む全域で
メッシュが裏返らないこと、古い首かしげ補間・顔パーツ変形を描画経路が使わないことを追加。
420フレームの切り替えに加え、180フレームの傾き保持＋連続口パク＋瞬き＋反転を確認する。
差分指標だけでなく実Electron/WebGLとCanvas2DのPNG・動画を目視確認する。
これは合成音声レベルによる描画検証で、実マイクや実TTSの会話試験ではない。
現行コードのアプリ1064件・静的58件・型検査、600フレーム、実Electronの6状態・
首かしげ発話閉眼・Canvas2D・キャラ変更/OFFの検査が通過。

### 瞬き・表情交換の再チェックと追加修正

以前の目スプライトには肌・頬も含まれ、その矩形を縮めると頬の縦筋や継ぎ目が出た。
現在は登録済みの開眼／閉眼原画の差分で探索領域を限定し、白目・虹彩・まつげだけを
一つの透過スプライトとして動かす。周辺の肌は拡縮しない。閉眼原画から薄いまつげを
二次元補完して下地を作り、局所的な色差のみ補正する。PNG原画は変更しない。

- 瞬きの中間形は原画の曲線状の閉じたまぶたへ変形する。平らな線への圧縮や、
  目の二重クロスフェードは行わない。透明境界はpremultiplied補間で扱う。
- すでに閉眼している笑顔・あくびは白目の量で判定し、瞬きによる再圧縮をしない。
- 表情マスクは上下両方の眉の範囲を所有し、交換前の眉が外側に残る二重化を防ぐ。
- 表情交換は150msで閉じ、閉眼フレームを表示して70ms待って一度だけ確定、
  さらに40ms保持して140msで開く。途中で届いた要求は最新を予約し、開眼中は
  原画を交換しない。低fps・長い停止復帰でも閉眼を一度表示する。
  既存の自然な瞬きが完全閉眼ならその瞬間を利用する。動きを減らす設定は即時交換。
- 28個の小さな目スプライトを起動時に準備し、初めての表情だけ描画が止まるのを防ぐ。
  キャラ変更・OFFでキャッシュを解放する。追加のAPI呼び出しはない。

今回の再チェックは31件の描画ロジックテストに加え、実Windows Electronで600フレームの
表情・首かしげ・口パクと、525フレームの高速割り込み・閉眼を検査した。
後者はWebGL／Canvas2D／動きを減らす設定を別々に検査し、閉眼中だけの原画交換、
開眼中の再交換禁止、頬の固定チェック点の不変、各表情の目の抽出をassertする。
同じシーケンスの旧差分上限も変更せず通過し、拡大した中間フレームも目視確認した。
実UIの6状態・首かしげ発話閉眼・フォールバック・キャラ変更/OFFも再検査済み。
これは描画の合成入力試験であり、実会話の音声／Jevタイミングの保証ではない。
3セル原画の作画差は残るため、Live2D同等の完全な連続変形を保証しない。

## 操作

標準コハクを選択し、設定のJev連携・表情選択と
「コハク・作画アニメーション（v9）」をONにする。従来どおり既定OFF。
Jevは既存の会話分類で状態を選択するだけで、フレームごとの呼び出しはない。

| 会話入力 | 新素材 |
| --- | --- |
| thinking、ponder、explain、recoil | 首かしげ |
| listening、soft、reassure | 傾聴 |
| happy、celebrate、nod | うれしい同意 |
| exasperated | 疑いの横目 |
| 会話・音声入力がない待機時 | 低頻度のあくび |

動画を貼り付ける方式ではない。PNGの顔体・髪をCanvas/WebGLで合成し、
既存の音声レベル→連続した口の開度、瞬きコントローラへ接続する。
首かしげ中も同一の頭の中で口・目を更新し、通常姿勢への即時復帰はしない。
新しい表情4種は、添付の顔領域マスクで登録済みセルを顔体の下地へ合成する。
髪の根元・飾りは固定し、毛先に小さな独立バネ変位を加える。

## 以前の動きと切り替えの改善（首かしげ・顔補間方式は上記へ置換）

- 呼吸・左右上下の待機揺れ・小さな首の動き・胸の呼吸・発話時の反応を追加。
  既存の待機揺れON/OFF、呼吸・傾き・声の動きの強度設定を引き継ぐ。
- 首のバネは表情を割り込ませても現在の位置と速度を維持する。
  新しい表情は首が通常位置へ戻り切るまで待たず、顔の内側で開始する。
- 48コマと両端の高解像度画像を同じ連続列で補間。丸めによるコマ飛びと
  終端の別画像への即時切り替えをなくした。
- 表情同士の切り替えは表示中のセルから次の開始セルへ直接移行し、
  「旧表情→一瞬通常顔→新表情」の迂回をしない。会話中はピーク表情を保持する。
- 目・口・眉の局所形状を、表示中と次の原画の両側で位置合わせしてから混ぜる。
  首かしげ中の探索領域も顔に追従。口は暗い輪郭だけでなく内側の色も検出する。
- 顔マスクを内側へ縮め、元の頭・顎の輪郭は保持する。目・口の変化にも
  中間値を設け、発話開始・終了や瞬きで急に別の顔を貼り付けない。
- 毛先は首の速度に遅れて追従する。OSの動きを減らす設定では体と髪の揺れを停止。

髪の「ふわっと感」調整では、中間の長さと毛先を別のバネに分離し、深さに応じた
しなりを追加した。毛先は少し柔らかい減衰で頭の動きを追いかけ、弱い戻りを伴う。
横方向だけでなく上下方向も遅れて動く。波の位相は左右で少しずらすが、フレームごとの
ランダムなノイズは加えない。顔・髪の根元・飾りはこの独立変位では動かさない。
追加の浮遊感調整後、既定の毛先サンプル（1254px原画の380,950、10秒間）は
左右約−15.3〜+15.5px、上下約−4.5〜+4.5px。周期は少し長くし、体の左右上下の
揺れも拡大した。表示時はキャラの縮小率に応じて小さくなる。
「髪の揺れ」「髪のバネ」を既存設定から接続し、揺れ0・凍結・動きを減らす設定では停止。
待機揺れOFFでは待機時の波を止め、会話による頭の動きへの追従だけを残す。
原画上の独立変位は滑らかな制限で横22px・縦9px以内に収める。
ふわっと感調整後はアプリ1056件・静的58件、420フレームの切り替え回帰検査、
実ElectronのWebGL/Canvas2D描画検査が通過。30/60/144fpsの安定性、長時間の停止復帰、
首の反転時の連続性、最大強度でもメッシュが裏返らないことも検査する。

### 口が二重になる問題の修正

表情原画には口が描かれているため、後から口パクを透明に重ねる方式では、元の口が
残ることがあった。さらに縮小で細い笑い口が分断され、顎の影を口と誤検出したり、
喜び顔の上側を狭い探索範囲で見落としたりしていた。

- 探索範囲を全表情に合わせ、境界につながる顎の影を除外。近接した唇の断片を統合。
- 各顔の唇・口内・歯だけを小さな透過スプライトへ分離し、**顔を補間する前に元の口を除去**。
  鼻や顎まで含む大きな肌色パッチで塗りつぶさない。原画PNG自体は不変更。
- 表情と音声の口は同じ一つの描画レイヤーで合成し、下地に別の口を残さない。
  開いた口の高さは連続的に変え、閉じた唇を開いた口の高さまで引き伸ばさない。
- 通常の音声では3段階PNG切り替えではなく連続的な開き具合を渡す。検証用の強制口状態は維持。
  無音後の保持は500→180msとし、終了時は表情の口へ戻す。
- キャッシュするのは小さな口スプライトと除去用パッチのみ。大きな顔Canvasは再利用し、
  キャラ変更・OFFでは追加キャッシュも解放する。ネットワーク推論・音声処理の追加なし。

420フレームの回帰検査で64枚の顔画像（首かしげ全コマ・全表情セル・口差分）
すべてから口を抽出できることをassertする。
首かしげ＋発話、表情間の移行、発話開始・終了の中間フレームも目視確認。
アプリ1058件・静的58件と型検査が通過し、実ElectronのWebGL/Canvas2D描画・
キャラ切り替え・OFFも確認（100回のRAFで51回の描画更新、約1.66秒）。
目のセル補間による淡い混合は別の制約であり、全アニメーションの完全な自然さは保証しない。

提供された3セルを補間する範囲なので、全表情を連続作画した動画やLive2Dモデルと
同等の再現ではない。中間フレームの淡い混合は残り得る。数値検査だけで
自然さを保証せず、比較動画・中間フレームの目視確認も行う。

## 初期統合時の実装範囲と制限（現在の変更点は冒頭参照）

- 元パッチは古いHEADへのプレビュー専用。無条件適用・付属スクリプト実行はせず、
  現行のキャラ選択・Jev・配布・静的サーバーに手動で接続した。
- 48コマの首かしげは添付の透明レイヤー補間を利用。
- 新4種は原画3セルを短くブレンドする。プレビュー動画のRIFE補間品質を
  そのまま再現する実装ではない。全v8作画キーは今回の添付に含まれない。
- 首かしげ中の目・口は3点位置合わせの局所パッチ。全顔へのyaw/スキューは掛けない。
  独立作画された全ポーズ×6差分と同等の品質保証ではなく、視覚調整の余地がある。
- 残っている旧手ポーズ素材は後方互換・再制作テスト用。PCのコハク拡張では送らず、
  起動時もデコードしない。OFF時は従来の標準コハクへ戻る。
- 読み込み失敗・描画異常時は通常描画へフォールバック。
  キャラ変更・OFF時はAbortControllerとdisposeでロード・画像・GPUを解放する。
- decoded画像は最大640px、計約130.4 MiB。GPU髪テクスチャは最大8枚。
  ブラウザ・旧基本素材・一時Canvas等のメモリは別。OSの動きを減らす設定では
  体・髪の揺れと局所変形を停止し、口・目は維持する。
- RLCDの1bit線画、マイク、Wi-Fi、音声再生の処理は変更しない。ファーム書換え不要。

## 検証手順

```bash
node --test desktop/tests/drawn-pose-runtime.test.cjs
npm run test:desktop
uv run python -m unittest tests.test_project_static
```

Windows Electronで、別プロファイルとローカル静的サーバーのみを使ったテスト:

```text
electron scripts/kohaku-motion-ui-smoke.cjs SOURCE FRESH_OUTPUT
```

6状態のPNG、首かしげ＋口・閉眼、WebGLとCanvas2D fallback、キャラ変更・OFFを確認。
統合時はアプリ1044件・静的58件が通過。Windows Electronで100回のRAF中51回の
描画更新を確認した（1.66秒、約31描画/秒）。これは検証環境での観測値で、性能保証ではない。
音声は合成入力値を用いた描画検証で、実マイク・実TTS・実Jevの会話テストではない。
`?kohakuMotion=1` は検証用の状態確認APIを出す。OBSではこのクエリだけでは有効化せず、
標準コハクかつスナップショットの明示フラグを必須とする。

切り替えの回帰検査（420フレーム、30fps、合成入力。個人プロファイルやAPIへ接続しない）:

```text
electron scripts/kohaku-motion-transition-qa.cjs SOURCE FRESH_OUTPUT
```

瞬きの肌巻き込み・原画交換タイミングの回帰検査（525フレーム、別プロファイル）:

```text
electron scripts/kohaku-motion-face-qa.cjs SOURCE FRESH_OUTPUT
```

各フレームのPNGと `report.json` を保存する。出力先は既存フォルダを指定できない。

待機→首かしげ→喜び→疑い→傾聴→通常→あくびと、発話・瞬きの割り込みを検査する。
各フレームのPNGと `metrics.json` を出力し、全体・顔の差分上限、瞬きの中間値、
待機中の動き、首の即時リセット防止をassertする。差分上限はこの検証シーケンス用で、
美しさや別GPUでの完全一致を保証するものではない。

今回の調整では複数案を描画して見直し、同じシーケンスの最大フレーム差分は
全体9.45→6.96、顔14.55→8.49（RGBAからの差分指標）となった。
切り替え改善時のアプリ1052件・静的58件の検査が通過。実UIの描画・フォールバック・
キャラ切り替え検査も行う。素材の再生成、追加のJev呼び出し、音声処理の変更はない。
