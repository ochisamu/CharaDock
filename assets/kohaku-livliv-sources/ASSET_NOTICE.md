# Kohaku rig source plates

These source plates were made from the project-original CharaDock Kohaku character using OpenAI's built-in image generation tool, at the user's request to prioritize quality and generate missing materials. They retain the character conditions described in DISTRIBUTION_ASSET_LICENSE.md at the repository root. They are not covered by the player code's Apache-2.0 license and are not a standalone reusable character asset pack.

`v2/generation.json` records the exact prompts and saved outputs. Runtime model files are built into assets/amber-avatar/livliv; the source plates are development inputs and are not part of the packaged application's asset include list. Runtime rendering and control do not call the image generation service.
